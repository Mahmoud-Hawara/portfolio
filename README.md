# Mahmoud Hawara — Portfolio

A premium GitHub-inspired portfolio built with Next.js, TypeScript, Tailwind CSS, Framer Motion, and shadcn/ui.

## Stack

- **Next.js 16** (App Router)
- **TypeScript**
- **Tailwind CSS v4**
- **Framer Motion**
- **shadcn/ui**

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Customize

Edit `src/data/portfolio.ts` to update content, links, experience, projects, and skills.

## Design

- GitHub dark palette (`#0d1117` background)
- Green accent CTAs, blue links
- Terminal UI, contribution heatmap, repo-style project cards
- Timeline experience section with subtle animations
